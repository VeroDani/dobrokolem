## What I learned
- The hard part isn't technology, it's giving organisations a reason to keep their data current.
- Verification by hand took roughly one evening for 71 records with AI assistance. That's the baseline to beat.
- First GitHub upload: dragging the whole folder nested everything one level too deep, so the README didn't render. Fix: upload the *contents* of the folder. Recreated the repo for a clean history.
- Connected Claude to the repository in two steps: link the GitHub account in Claude (identity), then install the Claude GitHub App on this one repository (write permission). Same principle as for the agents: grant access only where it's needed.
- From now on, agents commit changes and I review them in the GitHub history instead of uploading files by hand.

## First agent evals (same evening)
Verifier went v2 → v3 → v4 in three runs: 10/20 → over-corrected → **19/20, pass**. The big lesson: v3 didn't fail because of the prompt but because one field (`status`) was answering two questions – *is it correct?* and *is it complete?*. Splitting them (D-011) fixed it and halved the cost. Also: the agent found an error in my own "golden" answers (Oděvní banka became independent). Reference data needs versioning too.
